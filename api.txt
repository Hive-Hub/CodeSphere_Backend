2. GLOBAL RESPONSE & ERROR FORMATS
--------------------------------------------------------------------------------

Success Response Payload (HTTP 200 / 201 / 202):
{
  "success": true,
  "message": "Operation description",
  "data": { ... },
  "meta": null,
  "error": null
}

Error Response Payload (HTTP 400 / 401 / 403 / 404 / 413 / 429 / 500):
{
  "success": false,
  "data": null,
  "error": {
    "code": "ERROR_CODE",
    "message": "Human readable message",
    "details": []
  }
}

Standard Error Codes:
- BAD_REQUEST (400)
- VALIDATION_ERROR (400)
- DUPLICATE_ROLL_NUMBER (400)
- SESSION_INACTIVE (400)
- INVALID_MODE (400)
- LANGUAGE_MISMATCH (400)
- CODE_TOO_LARGE (413)
- INPUT_TOO_LARGE (413)
- UNAUTHORIZED (401)
- FORBIDDEN (403)
- NOT_FOUND (404)
- AI_RATE_LIMITED (429)
- COMPILER_UNAVAILABLE (503)
- COMPILER_TIMEOUT (408)
- INTERNAL_SERVER_ERROR (500)

6. REDIS V2 ARCHITECTURE & DATA STRUCTURES
--------------------------------------------------------------------------------

Redis is used exclusively for transient live session state (with explicit TTLs):
- session:{session_id}:online_students -> SET of student_ids (TTL: 86400s)
- session:{session_id}:typing_students -> SET of typing student_ids (TTL: 300s)
- session:{session_id}:running_students -> SET of running student_ids (TTL: 86400s)
- student:{student_id}:presence -> HASH (status, last_active, sid) (TTL: 3600s)
- student:{student_id}:code -> STRING live editor buffer (TTL: 86400s)
- student:{student_id}:cursor -> STRING line & column json (TTL: 86400s)
- student:{student_id}:typing -> STRING status flag (TTL: 300s)

Connection Pool Configuration:
- max_connections: 50
- socket_timeout: 5.0s
- socket_connect_timeout: 5.0s
- retry_on_timeout: True

7. WEBSOCKET EVENTS SPECIFICATION (FLASK-SOCKETIO)
--------------------------------------------------------------------------------

Socket.IO Connection:
- Path: /socket.io/
- Transports: websocket, polling

Events Emitted by Client:
  - student_join_session: { "session_id": 1, "student_id": 1, "name": "Name" }
  - teacher_join_session: { "session_id": 1 }
  - code_change: { "session_id": 1, "student_id": 1, "code": "..." }
  - typing_start: { "session_id": 1, "student_id": 1 }
  - typing_stop: { "session_id": 1, "student_id": 1 }
  - cursor_change: { "session_id": 1, "student_id": 1, "line": 5, "column": 12 }

Events Broadcast by Server (Room session:{session_id}):
  - student_joined / student_left / student_online / student_offline
  - student_code_updated / student_typing / student_stopped_typing / student_cursor_updated
  - compiler_started: { "event": "compiler_started", "session_id": 1, "student_id": 1, "language": "python", "timestamp": "..." }
  - compiler_completed: { "event": "compiler_completed", "session_id": 1, "student_id": 1, "language": "python", "status": "success", "exit_code": 0, "execution_time": "0.04s", "memory": "12MB", "output": "...", "error": "..." }
  - ai_analysis_started / ai_analysis_completed / ai_progress_updated
  - session_ended: { "event": "session_ended", "session_id": 1, "reason": "teacher_ended" | "24_hour_expired" }
